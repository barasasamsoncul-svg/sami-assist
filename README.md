# SaMi Assist — All Apps Package

Adds a common workspace for every currently registered SaMi app.

Routes:
`/dashboard/apps/<route>`

Examples:
`/dashboard/apps/invoicing`
`/dashboard/apps/inventory`
`/dashboard/apps/accounting`
`/dashboard/apps/projects`

Run `npm run build` after extraction.

See ALL-APPS-SCHEMA-AUDIT.md.
